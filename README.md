# EcomPhash

## About the Project

EcomPhash is an e-commerce web application developed using ASP.NET Core MVC and SQL Server.

I created this project to practice and strengthen my .NET development skills, implement authentication concepts, and prepare for technical interviews and practical machine tests.

## Technologies Used

- C#
- ASP.NET Core MVC
- SQL Server
- ADO.NET (if used in this project)
- HTML5 and CSS3
- Bootstrap
- JavaScript and jQuery (if used in this project)
- Git and GitHub

## Concepts Practiced

- MVC architecture and routing
- Controllers, models, and Razor views
- User registration and login
- Password hashing using BCrypt
- JWT token generation and validation
- Configuration management
- Database connectivity and SQL queries
- Git version control

## Project Structure

- `Controllers` — Handles incoming requests and application logic.
- `Models` — Defines application data models.
- `Views` — Contains Razor views for the user interface.
- `wwwroot` — Stores static files such as CSS, JavaScript, and images.
- `Program.cs` — Configures application services and middleware.
- `appsettings.json` — Contains application configuration settings.
